# About me

Small static personal landing page built with semantic HTML, CSS, and browser JavaScript.

## Development

```sh
npm install
npm start
```

## Production build

```sh
npm run build
npm run preview
```

The deployable static files are written to `build/`. They can also be served by any static web server, for example:

```sh
python3 -m http.server 8000 --directory build --bind 0.0.0.0
```
